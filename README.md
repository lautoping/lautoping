### Hola, soy Lautaro 

Estudiante de **Ingeniería en Mecatrónica** (UNCuyo). Me gusta llevar las cosas de punta a punta: desde el firmware de un microcontrolador hasta la app que usa alguien todos los días.

**Lo que hago**

- 🐍 **Python**: apps de escritorio, automatizaciones, procesamiento de datos y Excel, dashboards web.
- 🔌 **Embebidos**: firmware en C para STM32 y ESP32, motores paso a paso, G-code, comunicación serie.
- 🤖 **Robótica y control**: cinemática, trayectorias, control en Simulink/Stateflow, visión por computadora.

**Algunos proyectos**

- [**recibos-pileta**](https://github.com/lautoping/recibos-pileta) — reemplacé el cuaderno de recibos de una pileta por una app: calcula cuotas y descuentos, maneja pagos parciales y guarda todo en Excel.
- [**CNC láser con STM32**](https://github.com/BPera1111/Proyecto_Micro) — convertimos una impresora 3D en una CNC láser, con firmware propio y planificador de movimiento.
- [**Grúa STS**](https://github.com/BPera1111/AyCD) — simulador de una grúa portacontenedores con control en tres niveles y un dashboard web en tiempo real.
